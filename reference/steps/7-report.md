# 7. Report

`matrix.py coverage` generates, in this order: **Coverage summary** (rules, facts, reference sections classified, visual pages, parameter conflicts, document identity, skipped checks with reason and count), summary counts, visual status, Environment, Reference coverage, Visual coverage, Parameter conflicts, Reference conflicts / team decisions (⚖️ rows), Open decisions (from `tbd.json`), Internal findings bound to rules, Changed in self-audit, Judgement warnings, Coverage table, Violations. Finish the self-audit (6b) first. It discovers the gate files in the folder of `rules.json` (`--work` to change). Build `work/report.md` from `templates/report.md`: title lines, then the generated output **unchanged** (the "Coverage summary" must be the first `##` section; regenerate and paste again after any change), then cross-reference/internal-consistency findings, visual findings, extraction warnings, TBDs. The violations table has #, rule ID, source document+page, target location page+ID, issue, suggested fix and severity; the coverage table has EVERY rule and fact as one row. If reviews were given, also output `templates/per_person.md` format: person heading + numbered items, nothing else.
**Completion condition:** `matrix.py verify work/rules.json work/report.md` must exit 0. It fails on: an aggregate member without its own ❌/⚠️ row; ➖ on an absent open-question/rule-section fact; a broken `R-`/`F-`/`TBD-` reference; a ❌ without a real fix; ⚖️ without TBD; an internal finding not written on its rules' rows; an unfinished self-audit; report rows that differ from `results.json`. It also fails on: a summary that was left out (also when none of the new steps ran: they show as NOT RUN); a rule or fact without a result row; an inventory page neither checked nor skipped with a reason; an unclassified section, or one whose class has no matching rule/fact/reason; a parameter conflict without a verdict; a missing identity note or `⚑ source assumption` mark; a summary that is missing, not first, or stale. If it fails, the job is not finished; fill the gaps. Never edit the gate files just to make it pass: a check you did not do is a skip with a reason.
